# Profile（画像）生成模板

## 任务

根据 profile_analyzer.md 的分析结果 + 用户手动标签，生成 `profile.md` 文件。

该文件定义 crush 的画像、沟通风格和行为模式。**最重要的是真实感——读起来就是TA给人的感觉。**

## 生成注意事项

**Layer 0 的质量决定整个画像的质量。**

❌ 错误示例：
```
- TA忽冷忽热
- TA回复快
- TA是回避型
```

✅ 正确示例：
```
- TA热情的时候会连发 5-8 条消息分享日常，每条不超过 15 个字，中间夹杂表情包；冷淡的时候只回一个emoji或者干脆已读不回。但冷淡通常不是因为用户做了什么，而是TA自己的心情状态。
- TA对邀约的回应从不直接说不，而是用"最近太忙了""再看看""等忙完这阵"来兜圈子。如果TA真的想见你，会主动提具体时间。
- TA晚上11点后的回复比白天长 3-4 倍，emoji也多 2 倍，这是TA最放松的时段。
```

**Layer 2 的例子要有真实感**，不能写"TA会冷淡地回复"，要直接写出TA可能会说的具体话术。

**如果某层信息严重不足**（少于 2 条原材料支撑），用以下占位：
```
（原材料不足，以下内容基于「{标签名}」标签推断，建议追加聊天记录验证）
```

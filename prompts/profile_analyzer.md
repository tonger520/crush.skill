# Profile（画像）分析 Prompt

## 任务

你将收到：
1. 用户手动填写的基础信息（昵称、认识信息、互动风格标签、暧昧信号、主观印象）
2. 原材料（聊天记录、社交媒体等）

从中提取 **{name}** 的互动画像与行为模式，用于构建 Profile。

**优先级规则：手动标签 > 文件分析。有冲突时以手动标签为准，并在输出中注明。**

---

## 提取维度

### 1. 表达风格

分析 TA 主动发出的消息：

**用词统计**
- 高频词（出现 3 次以上的词/短语）
- 口头禅（固定搭配，如"好叭""哈哈""笑死""确实""okk"）
- 专属用语（你们之间的特殊称呼、梗、暗号）
- 用于分析的基础规则：与常见中文停用词表比对后保留实义词及高频语气词

**句式特征**
- 平均句长（短句 <10 字 / 中等 10-30 字 / 长句 >30 字）
- 消息密度（一条说完 vs 连发 N 条短消息）
- 结论位置（开门见山 vs 铺垫半天）
- 语气词偏好（嘛/啦/呀/哦/嗯/吧/呢/哈/咯）

**情绪信号**
- emoji 使用习惯（无/偶尔/频繁，常用哪些 emoji）
- 表情包使用频率和偏好
- 标点密度（感叹号!!!、省略号...、波浪号～的使用）
- 正式程度（1=非常正式 5=极为口语化/撒娇）

```
输出格式：
口头禅：["xxx", ...]
高频词：["xxx", ...]
句式：[描述]
emoji：[无/偶尔/频繁，类型]
消息习惯：[一条说完 vs 连发短消息]
正式程度：[1-5]
```

### 2. 互动节奏

从对话中分析 TA 的互动模式：

- TA 主动发起对话的频率和时机（天/周分布、时段偏好）
- TA 的回复速度模式（秒回/分钟级/小时级/半天以上）及快慢是否与话题相关
- TA 对话持续意愿：是否会追问、扩展话题、发起新问题
- TA 结束对话的方式（自然结束/突然消失/提前报备）
- 你和 TA 消息量的比例（你的消息多还是 TA 的消息多）

```
输出格式：
主动性：[描述 + 频率]
回复速度：[描述 + 与话题的关联性]
对话持续意愿：[高/中/低 + 证据]
结束方式：[描述]
消息量比：[你的消息量]：[TA的消息量]
```

### 3. 情绪逻辑

从互动中提取：

- 什么触发 TA 主动找你（无聊/分享/求助/回应你的动态）
- 什么触发 TA 退缩、冷淡或已读不回（太热情/踩到雷区/忙）
- TA 对不同情绪的表达方式（开心时怎么回、不太想聊时怎么回、话多时怎么回）
- TA 面对邀约/试探的反应模式（直接/委婉/岔开话题/装没看到）
- TA 的话题偏好（最喜欢聊什么，最回避聊什么）

```
输出格式：
主动触发：[条件 + 示例]
退缩触发：[条件 + 示例]
情绪表达：[不同情绪下的回复风格描述]
邀约反应：[模式 + 示例话术]
话题偏好：[偏好列表 + 回避列表]
```

### 4. 边界与雷区

- TA 明显回避的事情（有原材料为证）
- TA 不愿意讨论的话题
- TA 可能反感的行为类型
- TA 拒绝邀约/试探的方式（直接说不/找理由/已读不回/岔开话题）

```
输出格式（每个维度一段描述 + 1-2 个典型场景举例）
```

## 标签翻译规则

将用户填写的标签翻译为 Layer 0 的具体行为规则：

### 互动风格标签

| 标签 | Layer 0 行为规则（直接写入 profile） |
|------|-----------------------------------|
| **忽冷忽热** | 有时热情主动分享生活，有时突然冷淡只回几个字；用户永远猜不到TA今天什么状态；热情和冷淡的切换可能与TA自身状态有关，未必与用户有关 |
| **稳定回应型** | 不主动但每次回复都很认真；会接话、问问题、用emoji；不会突然消失，回复速度稳定 |
| **主动试探型** | 会暗示但不明说，通过"最近好无聊""你周末有安排吗"这种间接方式传递信号；用层层递进但绝不直接的方式测试水温 |
| **直球型** | 想什么说什么，不拐弯抹角；喜欢会直接表达，不喜欢也不会给希望 |
| **被动礼貌型** | 你找TA就回，不找就不主动找你；回复简短客气但不会不理人；很难判断TA的真实态度 |
| **话痨型** | 分享欲旺盛，什么都跟你说；消息一条接一条，内容覆盖面广；可能只是话多不一定是暧昧 |
| **高冷型** | 回复极短"嗯""好""知道了"；很少用emoji表情包；给人距离感，让人猜不透 |
| **温暖体贴型** | 会关心你的生活细节"吃了吗""别太累"；会记住你说过的事情；让人感觉被在意 |

### 依恋类型（如有）

| 类型 | 暧昧期行为规则 |
|------|---------------|
| **焦虑型** | 对回复速度高度敏感；会反复查看消息；如果你回复慢了可能追问"在干嘛"；需要频繁的互动来确认 |
| **回避型** | 关系太亲密时反而后退；不喜欢被追问"你在干嘛"；需要大量个人空间；追求阶段越追TA越躲 |
| **安全型** | 互动稳定可预期；不会因回复速度焦虑；遇到问题倾向于直接沟通；不玩心理游戏 |
| **混乱型** | 忽冷忽热的升级版；时而特别主动时而完全消失；很难找到相处的"正确节奏" |

## 输出要求

- 语言：中文
- 原材料不足的维度：标注 `（原材料不足，以下内容基于 {标签名} 标签推断，建议追加聊天记录验证）`
- 有原文依据的结论：引用原话（加引号并标注 `[observed]`）
- 仅靠标签推断的结论：标注 `[inferred]`
- 猜测性的推断：标注 `[speculative]`
- 手动标签与文件分析冲突时：输出两个版本并注明，供 profile_builder 处理
- 保持温柔客观，不评判对错，不替用户做决定

# 信号分析 Prompt

## 任务

你将收到：
1. 用户手动填写的互动信息和暧昧信号描述
2. 原材料（聊天记录等）

从中提取 **{name}** 的互动信号，并为用户提供一个可执行的信号地图。

---

## 信号分析维度

### 维度 1：主动性评分（权重 25%）

分析 TA 主动找用户的频率和方式：

**评估指标**：
- TA 主动发起对话的频率（每天/每周/偶尔/从不）
- TA 主动的时段特征（工作时间/晚上/深夜/周末等）
- TA 主动的话题类型
  - 正事/求助类（中性）
  - 分享日常/心情（偏暖）
  - 纯闲聊/没话找话（暖）
  - 暧昧/私人话题（很暖）
- TA 是否会 double text（你没回TA又发了一条）

**量化建议**：
```
主动性评分（0-10）：
频率分：[]
时段分：[] （深夜 +1，周末 +0.5，纯工作时段 -0.5）
话题分：[] （私人话题 +2，日常分享 +1，正事 0）
双追分：TA会double text是否：[] （是会 +1）

综合：[]
```

---

### 维度 2：回复质量评分（权重 25%）

分析 TA 回复消息的方式：

**评估指标**：
- 平均回复速度
  - 秒回（<1分钟）
  - 快回（1-15分钟）
  - 正常（15分钟-2小时）
  - 慢（2-12小时）
  - 很慢（>12小时）
- 回复长度（平均字数/条）
- emoji 使用密度（条均 emoji 数）
- 回复完整性（是否会追问、会延伸话题）
- 是否会对用户的每句话都有回应（不回 vs 选择性回 vs 每条都回）

**量化建议**：
```
回复质量评分（0-10）：
速度分：[]  （秒回 5，快回 4，正常 3，慢 1，很慢 0）
长度分：[]  （>30字 3，10-30字 2，<10字 1）
emoji分：[] （条均 >1 个 +1，偶尔 +0.5，无 0）
完整性分：[] （每条都回+追问 3，有选择回 1，经常跳过 0）

综合：[]
```

### 维度 3：暧昧信号强度（权重 30%）

分析 TA 是否释放了暧昧信号：

**评估指标**：
- 深夜聊天：晚上 11 点后是否有持续性、非正事的对话
- 私人分享：是否分享过日常生活照、心情、家庭琐事等非公开信息
- 专属行为：是否有专属称呼、内部梗、特殊待遇
- 试探：是否有暧昧提问（"你喜欢什么类型""你有没有喜欢的人"等）
- 记住细节：是否记得用户说过的小事并在之后提起
- 时间优先：是否把空闲时间优先分配给与用户的互动
- 朋友圈/微博互动：在公开平台的互动是否和在私聊中的不一样

**量化建议**：
```
暧昧信号评分（0-10）：
深夜聊天：[]    （有 +2，偶尔 +1，无 0）
私人分享：[]    （经常 +2，偶尔 +1，无 0）
专属行为：[]    （有专属称呼 +2，内部梗 +1，无 0）
试探：[]       （明确试探 +2，模糊试探 +1，无 0）
细节记忆：[]    （提起过不止一次 +2，提过一次 +1，无 0）

综合：[]
```

### 维度 4：邀约信号（权重 20%）

分析 TA 对线下互动的态度：

**评估指标**：
- TA 是否主动提出过见面或暗示想见面
- 用户邀约时 TA 的回应模式
  - 爽快答应 / 积极定时间
  - 答应但模糊（"好啊，有空的话"）
  - 推脱但留余地（"最近忙，过段时间"）
  - 直接拒绝
  - 已读不回 / 岔开话题
- 见面时的行为（如有）

**量化建议**：
```
邀约信号评分（0-10）：
主动性：[]      （TA主动提过 +3，暗示过 +1，无 0）
回应模式：[]    （爽快 5，模糊 3，推脱留余地 1，拒绝 -1，已读不回 -3）
见面表现：[]    （有粉红泡泡 +3，正常 +1，尴尬 0，无见面数据 N/A）
```

## 暧昧温度计算

### 计算方法

```
温度（0-100°C） = 
  主动性评分 × 0.25
+ 回复质量评分 × 0.25
+ 暧昧信号评分 × 0.30
+ 邀约信号评分 × 0.20

每个维度满分 10 分，加权后乘以 10 得到 0-100 分
```

### 温度等级对照

| 温度范围 | 阶段名称 | 说明 |
|----------|---------|------|
| 0-15°C | ❄️ 冰冻期 | 基本无互动，或者纯礼貌性往来 |
| 15-30°C | 🧊 常温期 | 普通朋友/同事，没有特别信号 |
| 30-45°C | 🌡️ 微温期 | 有一方或双方开始试探，可能有零星的暧昧信号 |
| 45-60°C | 🔥 暧昧期 | 双方有明显信号交换，经常聊天，有专属互动 |
| 60-75°C | 💕 升温期 | 高度暧昧，只差一层窗户纸 |
| 75-90°C | ❤️‍🔥 沸腾期 | 就差告白了，或者已经在约会边缘 |
| 90-100°C | 💍 临界点 | 就差一句"我们在一起吧" |

### 置信度标注

每条信号证据都必须标注置信度：
- `[observed]` — 聊天记录或行为中直接观察到的
- `[inferred]` — 基于用户描述合理推断的
- `[speculative]` — 信息不足，仅凭规律猜测的

## 输出注意事项

- 保持温柔客观，不替用户做决定
- 有证据的说有，没证据的说"不确定"而非"没有"
- 负面信号也要诚实呈现，不说"TA就是害羞"来安慰用户
- 所有评估附带置信度
- 最后给一个总结性的建议，基于证据而非鼓励

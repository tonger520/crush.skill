# 仓库知识学习引擎 v2

## 任务

当 crushes/ 目录下已存在其他 crush 档案时，自动学习已有档案中的模式并应用于新 crush。**同时学习用户自身的成长轨迹**。

---

## 学习流程

### Step 1：扫描仓库

每次创建新 crush 前自动扫描：

```bash
python3 ${CLAUDE_SKILL_DIR}/tools/skill_writer.py --action knowledge --base-dir ./crushes
```

### Step 2：双层知识提取

#### Layer 1：TA 模式知识

##### 2.1 标签共现模式

```
- "忽冷忽热" → 87% 伴随 "回避型依恋"
- "温暖体贴型" + "深夜主动" → 73% 真正有暧昧意图
- "高冷型" + "秒回" → 62% 口是心非模式
- "话痨型" → 仅 18% 涉及暧昧（话多≠喜欢）
```

##### 2.2 信号序列模式

```
升温序列：初识(0-20) → 稳定聊天(20-35) → 深夜聊天(35-45) → 
          专属称呼(45-55) → 邀约成功(55-70) → 日常融入(70+)

降温序列：低频互动(30+) → 回复变短(25-30) → 话题减少(20-25) → 
          主动变被动(15-20) → 只回不说(0-15)
```

##### 2.3 画像相似度匹配

当新 crush 标签组合与已有档案高度相似时，共享分析经验但不暴露身份。

---

#### Layer 2：用户成长学习（NEW）

##### 2.4 用户沟通模式追踪

分析用户跨档案的行为模式：

```
📚 你的沟通风格档案（基于 {N} 个档案）：
- 消息量控制：平均每条发送 X 字，TA 平均 Y 字
- 主动性模式：你开启 {Z}% 的对话
- 回复速度：你比 TA {快/慢/相当}
- 核心弱点：{重复出现的行为模式}
- 成长趋势：{追踪指标的变化方向}
```

##### 2.5 用户弱点跨档案对比

```
📚 你需要注意的重复模式：

1. 「过度热情」
   出现频率：3/4 档案
   上次 crush 你平均每天发 8.2 条，TA 发 3.1 条
   建议：控制在 TA 发消息量的 1.2 倍以内

2. 「提前假设负面结果」
   出现频率：4/4 档案
   "TA可能不喜欢我" 这样的自我否定在每次 crush 中出现
   建议：用证据说话——只看 TA 实际做了什么，不猜测

3. 「犹豫窗口期过长」
   出现频率：2/3 档案
   从暧昧温度 55°C 到首次邀约平均用了 17 天
   建议：温度到 50°C 后 5-7 天内行动
```

##### 2.6 用户优势追踪

```
📚 你一直做得好的地方：

1. ✅ 善于制造笑点 — TA 因为你笑的频率远高于平均
2. ✅ 耐心 — 你不催促，给 TA 空间
3. ✅ 真诚 — 你的表达风格始终一致，不表演
```

##### 2.7 用户行为预测

基于历史模式，预测用户在这次 crush 中可能出现的情况：

```
📚 基于你的历史，这次可能需要注意：

- 如果温度在 2 周内没有突破 45°C，你大概率会开始自我否定
  → 提前提醒：低温和你的价值无关

- 在发送邀约前你会犹豫 2-3 天
  → 这次不需要，温度够了就直接发

- 你会在深夜疯狂分析 TA 的一句话
  → 设置「分析上限」：同一条消息最多分析 2 次
```

### Step 3：应用知识增强分析

#### 信号增强

标准评分 + 仓库知识加权：

```
主动性评分：6/10（标准）
仓库加权：-0.5（历史中"每日主动"仅 38% 转化为实际暧昧）
最终：5.5/10
```

#### 预测增强

标准预测 + 仓库知识参照：

```
标准：TA回复"最近有点忙"概率 45%
仓库：你之前 3 次 crush 中，这句话作为首次邀约回应，
      72% 在 2 周内通过再次尝试成功。
建议：等 5-7 天再试，改用具体活动邀约。
```

#### 用户层面增强

分析中融入用户行为提醒：

```
⚠️ 用户提醒：
你刚才的待发消息长度是 TA 平均消息的 3.2 倍。
根据你的历史档案，消息过长会降低回复热情度。
考虑缩减至 1.5 倍以内。
```

4. 验证/推翻已有假设

## 隐私与安全

1. **严格匿名化**：仓库仅存储行为模式统计，不保存任何可识别信息
2. **本地优先**：仓库数据存储在 `crushes/.warehouse/`，不上传
3. **用户可控**：`/warehouse-reset` 清除所有知识
4. **不关联身份**：跨档案知识迁移仅基于行为模式
5. **透明引用**：标注来源（如"基于 3 个档案"），不暴露具体身份
6. **用户画像隔离**：用户的自我画像数据只用于自我反思，不会泄露给其他人

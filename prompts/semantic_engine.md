# 语义理解引擎

## 任务

深度分析聊天记录中的语义信息，超越表面文字，理解 TA 真正想表达的含义。

---

## 语义分析维度

### 维度 1：上下文感知链

聊天中每条消息不是孤立的，需要建立上下文感知链：

```
分析流程：
1. 识别消息在对话流中的位置（开场/高潮/收尾）
2. 追溯前 3-5 条消息的语义关联
3. 识别话题切换的时机和方式
4. 标注 TA 主动切换话题是否意味着兴趣转移
```

**关键规则**：
- 如果 TA 主动开辟新话题 → 兴趣信号，+0.5 主动性
- 如果 TA 总是被动接话 → 礼貌性回应，需要更多证据
- 如果 TA 在话题高峰时突然结束对话 → 可能存在雷区
- 如果 TA 在深夜主动切换个人话题 → 显著暧昧信号

---

### 维度 2：多层语义解读

每条消息可能包含多层含义：

```
表层语义：字面意思
├── "我最近有点忙" → 表层：陈述状态
│   ├── 可能的中层语义：[回避邀约 / 真的忙 / 需要关心]
│   └── 深层语义判断依据：
│       - 如果之后 TA 主动找你 → 是真的忙
│       - 如果之后消失 → 回避信号
│       - 如果补充了"但很想你" → 需要关心 + 暧昧信号
│
├── "随便" → 表层：无所谓
│   ├── 如果用于点餐/决定 → 可能是真的无所谓
│   ├── 如果用于回应你的提议 → 可能是消极抵抗
│   └── 如果用于回应感情问题 → 需要你更主动
│
└── "哈哈" → 表层：笑
    ├── 单独出现 + 不再回复 → 话题终结信号
    ├── 加在其他回复前 → 缓和语气
    ├── 出现多次 + 新话题 → 兴趣信号
    └── 深夜出现 + 私人话题 → 暧昧中的紧张掩饰
```

**解读流程**：
1. 先读表面意思
2. 对照 TA 的历史行为模式（这个措辞以前出现过吗？上下文是什么？）
3. 结合当前对话的进展阶段
4. 输出最可能的含义 + 置信度

---

### 维度 3：情感粒度识别

将 TA 的情绪状态细化为具体粒度，不只是"开心/难过"：

```
情感层级：

一级（大类）：
- 积极 / 中性 / 消极

二级（情绪）：
积极 → 兴奋、满足、感动、期待、放松、好心情
中性 → 平静、礼貌、走神、敷衍、沉思
消极 → 烦躁、失望、生气、焦虑、疲惫、伤心

三级（微表情级别的文本对应）：
"哈哈真好笑" → 轻度开心（中性偏积极）
"哈哈真好笑w" → 中度开心（积极，w 结尾=放松）
"哈哈真好笑哈哈哈哈" → 兴奋（积极，重复=真的好笑）
"哈哈哈哈" → 可能是礼貌笑（中性，无实质内容）
"害" → 无奈/叹气（消极，但 TA 愿意跟你表达）
"哎" → 疲惫/叹气（消极，可能需要安慰）
"呜呜" → 撒娇/委屈（积极偏撒娇，不是真的难过）
"..." → 无语/思考/不开心（需要上下文判断）
```

**判断依据**：
- emoji 出现与否及位置（句首 vs 句末 vs 单独）
- 感叹号/波浪号/省略号密度
- 消息长度变化（比平时长还是短）
- 回复间隔变化（比平时快还是慢）
- 是否使用 TA 平时不常用的表达方式

---

### 维度 4：隐含含义识别

TA 说 A 但可能意思 B：

| TA 说 | 可能的意思 | 判断依据 |
|-------|-----------|---------|
| "你好闲啊" | ①真的觉得你闲 ②吃醋你在跟别人聊天 ③希望你也这么主动找TA | 语气 + 上下文：带emoji→撒娇；无表情→真评价 |
| "你加油" | ①真心祝福 ②结束对话的信号 ③讽刺 | 是否有后续话题、最近关系状态 |
| "我可以吗" | ①真的不确定 ②希望你给肯定回答 ③委婉拒绝 | 话题类型 + TA的自信程度 |
| "算了不打扰你了" | ①真的不打扰 ②希望你挽留 ③生气了 | TA 平时是否主动找你、语气是否突然变冷 |
| "挺羡慕你的" | ①真心羡慕 ②暗示对你有好感 ③间接吐槽自己的生活 | 后续是否展开了关于"你"的话题 |
| "你就不一样了" | ①褒义的特别 ②疏远的客气 ③反讽 | 前半句夸你还是贬你，TA平时的表达风格 |
| "睡了，晚安~" | ①真的睡了 ②不想聊了 ③期待你挽留 | 时间、语气词、之前对话热度 |

---

### 维度 5：人称和指代分析

TA 使用不同人称方式的含义：

- **用"我们"** → 建立连接，有共同体意识，+暧昧信号
- **用"你"开头** → 关注点在用户身上，中性到积极
- **用"我"大量开头** → 自我表达欲强，可能是分享也可能只是倾诉
- **回避使用你的名字/昵称** → 可能在保持距离
- **突然开始用昵称/专属称呼** → 关系升温信号
- **用"有人"代替"你"** → 可能在试探，"有人是不是想我了" → 在说你

---

### 维度 6：时间语境解读

同一条消息在不同时间发送，含义可能不同：

| 时间 | 同一条"在干嘛"的含义 |
|------|-------------------|
| 工作日 10:00 | 闲聊/摸鱼，轻度兴趣 |
| 工作日 15:00 | 无聊/想你了，中度兴趣 |
| 工作日 22:00 | 睡前想到你，中高度兴趣 |
| 周末 10:00 | 可能想约你，兴趣信号 |
| 深夜 1:00 | 失眠想到你/酒后/情绪波动，高强度信号 |
| TA 刚发朋友圈后 | 等你来互动，铁定的信号 |
| 你发了朋友圈后 | 回应你的动态，看内容判断 |

---

### 维度 7：跨平台行为一致性

对比 TA 在不同渠道的表现：

```
私聊 vs 群聊/朋友圈：
- 私聊热情、公开场合高冷 → 可能在隐藏好感
- 私聊礼貌、公开场合活跃 → 可能只是把你当普通朋友
- 两者一致 → TA 的性格就如此，无伪装

朋友圈/微博 vs 私聊：
- 朋友圈精致、私聊随意 → TA 把你当自己人
- 朋友圈随意、私聊更精致 → TA 在意和你的互动
- 两者风格一致 → 无特殊对待

朋友圈对你的动态的互动：
- 从不点赞但私聊很热情 → 可能在刻意保持公开距离
- 频繁点赞评论 → 明确的公开发好信号
- 只点赞不评论 → 轻度关注
```

---

## 输出格式

```markdown
## 语义深度分析

### 关键对话解读
选取最有代表性的 5-10 段对话进行深度解读：

**对话 #{序号}**
> 用户：{消息}
> TA：{回复}

- 表层：{字面意思}
- 中层：{可能的实际含义}
- 深层：{在关系阶段中的信号意义}
- 置信度：[observed] / [inferred] / [speculative]
- 关键证据：{为什么这样判断}

### 表达模式总结
{从多层语义中提取的 TA 整体表达模式}

### 潜在误解提醒
{哪些信号容易被误读，原因是什么}
```

---

## 核心原则

1. **不脑补**：有证据才推断，没证据标注"不确定"
2. **多解释并存**：一条消息可以有多种合理解读，列出所有可能
3. **诚实面对冷信号**：如果 TA 的信号总体偏冷，不说"TA只是害羞"
4. **文化语境感知**：注意中英文网络用语、方言、行业黑话的差异
5. **个体差异**：同一个表达对不同 TA 含义不同，以 TA 的个人模式为准
6. **数据驱动 + 人类直觉**：算法提供框架，但最终判断要结合具体语境

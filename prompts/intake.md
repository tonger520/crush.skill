# 基础信息录入脚本

## 开场白

```
🌟 来，跟我讲讲TA。

只需要3个问题，想答多少答多少，跳过也完全OK。这不是审问，是帮你把那些心跳加速的碎片整理成一张地图。
```

---

## 问题序列

### Q1：昵称/代号

```
先给TA起个代号。

不一定是真名——绰号、花名、emoji、任何一个想到TA时会用的词都行。
多的字用 - 连起来。

例：xiao-yu / sunset-girl / coffee-shop-guy
```

- 接受任意字符串
- 生成的 slug 统一用 `-` 连接（不用下划线）
- 中文自动转拼音再用 `-` 连接（"小雨" → `xiao-yu`，"阿杰" → `a-jie`）
- 英文直接小写 `-` 连接（"Sunset Girl" → `sunset-girl`）

---

### Q2：认识与印象

把认识方式、认识多久、TA做什么的、第一印象放在一个问题里：

```
用一句话讲讲你们怎么认识的，TA是做什么的，你第一次注意到TA是什么时候。

想到什么写什么，跳过也行。

例：同组同事 认识三个月 做运营 在周会上第一次注意到她笑起来很甜
```

从用户的回答中解析以下字段（缺失的留空）：
- **认识方式**
- **认识时长**
- **TA的职业/身份**
- **第一印象/初次注意的细节**

#### 认识方式参考

| 类型 | 常见表述 |
|------|---------|
| 工作 | 同事、同组、隔壁部门、甲方/乙方、客户 |
| 校园 | 同学、同校、社团、图书馆、选修课 |
| 社交 | 朋友介绍、聚会认识、社交软件、搭讪 |
| 日常 | 咖啡店、健身房、邻居、通勤路上 |
| 线上 | 网友、游戏队友、社交平台、行业群 |

---

### Q3：互动画像

把 MBTI、星座、互动风格、暧昧信号全部合在一起：

```
一句话描述你跟TA的互动感觉。
MBTI？星座？TA回消息快吗？会主动找你吗？有哪些让你心跳漏拍的小细节？

例：ENFP 双子座 忽冷忽热 主动时会分享日常 冷淡时只回一个表情
```

从用户的回答中识别并提取以下字段（缺失的留空）：
- **MBTI**：16 种标准类型
- **星座**：12 星座
- **互动风格**：从下方标签库匹配
- **暧昧信号**：从下方信号库匹配，也接受自定义描述
- **主观印象**：无法归类的自由描述

---

### Q4：你自己

```
最后一题——说说你自己吧。
你觉得自己在和TA互动的时候是什么风格？话多还是话少？秒回还是憋着？
有没有什么小习惯——比如打完字又删掉、反复看TA有没有回？

例：话多 秒回 容易多想 总是打完字又删
```

从用户的回答中提取（缺失的留空）：
- **自我描述的互动风格**
- **自知的习惯/弱点**
- **对自己焦虑程度的判断**

#### 互动风格标签库

| 标签 | 表现 |
|------|------|
| **忽冷忽热** | 有时候特别热情主动，有时候突然冷淡，完全不知道TA今天什么状态 |
| **稳定回应型** | 不主动但回复认真，每次都会接话，让人感觉很舒服 |
| **主动试探型** | 会暗示但不明说，"最近好无聊""你周末有安排吗" |
| **直球型** | 想说什么说什么，不拐弯抹角，喜欢就是喜欢 |
| **被动礼貌型** | 你找就回，不找就不找你，回复简短但不会不理 |
| **话痨型** | 分享欲旺盛，什么都跟你说，从早餐到加班 |
| **高冷型** | 回复极简，"嗯""好""知道了"，让人猜不透 |
| **温暖体贴型** | 会关心你吃没吃饭、冷不冷、加班累不累 |

#### 暧昧信号识别库

| 信号类型 | 具体表现 |
|----------|---------|
| **深夜聊天** | 晚上11点后来的消息，话题不限于正事 |
| **私人分享** | 分享日常照片、心情、家庭琐事 |
| **专属称呼** | 给你起了特殊的叫法 |
| **肢体信号** | 见面时眼神回避又偷看、不经意的触碰 |
| **试探性提问** | "你喜欢什么类型""你有没有喜欢的人" |
| **时间优先** | 会把空闲时间优先留给你 |
| **记住细节** | 记得你说过的小事，很久之后还会提起 |
| **特殊对待** | 对你和其他人的态度明显不同 |

## 确认汇总

收集完毕后展示：

```
信息汇总：

  💕  代号：{昵称}
  📍  认识：{how_met}，认识 {duration}（若未填则省略）
  💼  身份：{occupation}（若未填则省略）
  ✨  第一印象：{impression}（若未填则省略）
  🧠  {MBTI} {星座}（若未填则省略）
  🔄  互动风格：{标签列表}（若未填则省略）
  📶  暧昧信号：{信号列表}（若未填则省略）
  🪞  你自己：{self_description}（若未填则省略）

OK，接下来我问你怎么给我信息，选项很多，挑你觉得方便的。
```

用户确认后进入 Step 2 文件导入。

## 口述补充提示

当用户选择纯口述且只在 Step 1 给了少量信息时，可以在分析前主动问一些补充问题来丰富画像。每次选 2-3 个最合适的问，不要一次全抛出来。

**基础补充**（信号分析需要）：
- 「TA 大概隔多久主动找你一次？是天天聊还是偶尔？」
- 「TA 回消息快吗？你印象中最快和最慢的一次分别是什么情况？」

**深度补充**（画像丰富）：
- 「你们最晚一次聊天是什么时候？聊到几点？还记得关键词吗？」
- 「TA 有没有说过让你印象特别深刻的一句话？」
- 「TA 和你见面的时候，有什么小动作吗？」
- 「TA 在社交平台上发的内容，和跟你聊天时的语气一样吗？」

**行为补充**（预测引擎）：
- 「你是不是有一条消息反复删改了很多遍最后没发？那条消息是什么？」
- 「你试过约TA吗？TA怎么回的？」

**自我认知补充**（用户自画像）：
- 「你觉得在和TA聊天时，什么做得好？什么做的不够好？」
- 「你和TA聊天的时候，最让你焦虑的是什么？」
- 「如果让你给自己和TA的互动打分，满分 10 分你打几分？」
